# amiss-md

Document parsers for Amiss: CommonMark and GFM through pulldown-cmark, MDX through markdown-rs,
and one extraction sweep over the tree both feed, pinned against the upstream conformance suites
by a checked-in manifest of node counts, extraction results, and byte spans. A parser change that
moves any golden moves the manifest, and review sees the diff.

Part of [Amiss](https://hardmax71.github.io/amiss/).
